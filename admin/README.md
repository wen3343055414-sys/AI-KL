# 智作台服务端

独立 Node.js 管理与模型服务，保留管理登录、服务运行信息、多服务商/多模型、真实 Token 统计与限额、操作记录、网站及域名业务。运行时只使用 Node.js 24 内置模块。

从仓库根目录运行 `npm run start:admin`；也可在此目录运行 `npm start`。实际访问来源、端口、持久化目录、服务认证和加密主密钥通过环境变量传入，详见 [运行配置](../docs/runtime.md)。首次访问设置 10–128 字符的独立管理密码，没有预设密码。

## 模型连接

在 API 接口设置中添加服务商，配置协议、Base URL、密钥、超时与限额。支持 OpenAI 兼容、Anthropic Messages 和 Gemini generateContent 文本协议；获取目录或手动添加模型后启用并选择默认模型。目录可访问不代表账号拥有调用额度。

凭据通过 `SECRET_ENCRYPTION_KEY` 或秘密文件进行 AES-256-GCM 加密，接口与浏览器不回传明文。空白保留密钥，替换和清除需明确操作，变更来源或协议需重新提供凭据。主密钥单独保管，搬迁数据库时保留相同主密钥；旧系统专用密文需要重新输入对应连接密钥。

工作台通过可配置的 `MODEL_GATEWAY_URL` 和双方共享令牌访问 `/internal/model/config`、`/internal/model/chat`。模型请求去重、账号隔离、失败反馈与 Token 元数据保留；服务端不保存对话正文。用量与月限额按北京时间计算，未知 usage 不冒充零，限额不等同于服务商账单硬上限。

## 网站与域名

`WebsiteStore`、独立访客服务器与 `/api/websites` 保留网站草稿、修订、预览、发布快照、生成及导入导出能力。可选访客服务通过 `WEBSITE_PORT` / `WEBSITE_ORIGIN` 启用，来源与工作台和管理页分离；没有访客服务时不声称预览或发布成功。

管理页提供域名登记、启停、默认、移除、DNS/HTTPS 与工作台实例检测。实际解析和证书由接入平台配置。旧网站和域名数据不会被删除。

服务不执行主机启停、版本更新、容器控制、网络配置或隧道安装。进程与日志交给运行平台管理。

## 验证

```bash
npm test
```

测试覆盖管理认证、来源与 CSRF、跨系统凭据加密、协议、模型目录与用量、网站隔离与域名验证，使用隔离测试接口，不依赖收费模型账户。
