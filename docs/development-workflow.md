# 开发与交付流程

1. 检查工作副本、当前分支和远端；保留已有修改，在任务分支完成开发。
2. 工作台前端位于 `public/`，数据后端位于 `src/`，模型与管理服务位于 `admin/`。
3. 运行 `npm test`、`node scripts/check-source.mjs` 与 `npm run build`。界面变化另外运行 `scripts/auth-ui-check.mjs`。
4. 将需求、决定、修改与验证写入当日公开工作日志，审阅差异后提交和推送任务分支，经 PR 审阅交付，不自动合并主分支。

发布方式由目标环境决定。代码配置不绑定托管商、操作系统服务或主机路径；持久数据与凭据由运行环境保管，不进入 Git。运行入口与环境变量见 [运行配置](runtime.md)。
