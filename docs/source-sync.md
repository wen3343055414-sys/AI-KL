# 源码与业务数据

工作副本通过 Git 任务分支、提交和 PR 保存源码；只有远端可读取的提交才算完成备份。开始工作先检查状态与远端，存在未提交内容时检查并保留，不覆盖、reset 或强制推送。

工作台前端在 `public/`，后端在 `src/`，管理与模型服务在 `admin/`。应用源码和静态构建可交付到不同环境；运行配置由环境变量提供，见 [运行配置](runtime.md)。

账号、会话、业务内容、模型凭据、Token 统计与网站草稿保存在持久化数据目录中。Git 不负责同步这些数据。迁移服务需要备份并搬迁数据目录，同时保留加密主密钥与服务共享令牌；静态版本的浏览器存储通过 JSON 导入导出迁移。

发布和进程管理由目标平台负责。提交代码不代表应用已经上线，也不会触发主机安装或修改系统配置。真实 `.env`、数据库、密钥、日志、附件、截图与临时目录不提交公开仓库。
